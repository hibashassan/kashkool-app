# Kashkool (كشكول)

A household media app for iPhone, Android, Apple TV and Android TV. It gathers your own media servers, your friends' servers and the streaming services you pay for into one place to choose what to watch and listen to.

This repository only hosts the app's public pages:

- [Support](https://hibashassan.github.io/kashkool-app/support.html)
- [Privacy policy](https://hibashassan.github.io/kashkool-app/privacy.html)

The source code is private. Published by The Collective Mind.
